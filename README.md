## Bases de dados

Os dados da Coordenação Geral de Imigração Laboral (CGIL) pertencem ao Ministério da Justiça e Segurança Pública e apresentam registros de imigrantes que solicitaram autorização de residência com finalidade laboral. As bases podem incluir informações sobre país de nascimento, sexo, idade, amparo legal e ocupação.

Os microdados estão disponíveis na [base de dados DataMigra](https://portaldeimigracao.mj.gov.br/pt/base-de-dados/datamigra).

## Como usar este repositório

1. Instale o [R](https://cran.r-project.org/) e, opcionalmente, o [RStudio](https://posit.co/download/rstudio-desktop/).
2. Abra os scripts da pasta `2-aulas`.
3. Execute as bases e os códigos por partes para acompanhar o raciocínio.
4. Consulte os PDFs de apoio sempre que precisar revisar um conceito.
5. Compare minhas tentativas com os exemplos e gabaritos das listas.
